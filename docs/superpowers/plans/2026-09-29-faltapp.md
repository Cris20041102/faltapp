# Faltapp v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA multiusuario que calcula cuántas clases puede faltar cada estudiante, registra faltas, coordina con amigos y lleva agenda.

**Architecture:** FastAPI sirve la API JSON en `/api` y la PWA estática en `/`. Toda la matemática vive en `app/calc.py` (puro, sin DB); las rutas cargan datos del semestre, arman un `Plan` y llaman a `summarize`/`day_color`.

**Tech Stack:** Python 3.11+, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL (psycopg 3), PyJWT, pytest, httpx; JS puro + Tailwind CDN; Playwright para e2e.

**Spec:** `docs/superpowers/specs/2026-09-29-faltapp-design.md`

## Global Constraints

- UI y mensajes de error en español.
- Hash de contraseñas con `hashlib.pbkdf2_hmac` (stdlib), sin passlib/bcrypt.
- Modelos con tipos portables (tests en SQLite, prod en Postgres).
- `minimo = (min_pct*total + 99)//100`; cada bloque cuenta 1 sesión.
- Colores del semáforo exactamente: `gris`, `asistio`, `falta`, `verde`, `amarillo`, `rojo`.
- Recurso ajeno → 404. Amigo solo ve colores, nunca ramos.
- weekday: 0=lunes … 5=sábado.
- `DATABASE_URL` y `JWT_SECRET` por env; `postgres://` se reescribe a `postgresql+psycopg://`.

## Review Focus

1. **Zona horaria de "hoy":** el servidor corre en UTC; a las 22:00 en Chile ya es "mañana". Los endpoints que usan hoy (`summary`, `friends/{id}/calendar`, `proposals`) aceptan `?today=YYYY-MM-DD` y el frontend envía la fecha local. → test en Task 4.
2. **Faltas fuera de rango tras editar fechas/feriados:** una falta cuya fecha ya no es día de clases de su slot no cuenta. → test en Task 1.
3. **Aceptar propuesta sin clases ese día:** se acepta sin error y sin marcar faltas. → test en Task 5.
4. **Usuario con mayúsculas/duplicado:** `Cristian` y `cristian` son el mismo; duplicado → 409. → test en Task 2.
5. **Solicitudes raras:** a uno mismo → 400; si B ya pidió a A y A pide a B → se acepta automáticamente. → test en Task 5.

  @dataclass class Plan: start: date; end: date; off: set[date]; courses: list[Course]; slots: list[Slot]; absences: set[tuple[int, date]]  # (slot_id, date)
